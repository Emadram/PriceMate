# 🗺️ PriceMate Development Roadmap

## Phase 1: Administration & Management (Immediate Next Step)
The goal is to provide a robust backend interface to manage the data we are now successfully displaying.

- [ ] **Admin Dashboard**: Visual analytics (Total Products, Prices, User Activity).
- [ ] **Product Management**: Create, Edit, Delete products with image upload support.
- [ ] **Price Management**: Interface to update prices for supermarkets without using scripts.
- [ ] **Data Validation**: Tools to identify and fix "orphan" prices or products without images.

## Phase 2: User Experience Core
Enhance the app to be more personalized and useful for daily shopping.

- [ ] **User Authentication**:
    - [ ] Sign Up / Login (Email & Password).
    - [ ] OAuth (Google Sign-in).
    - [ ] User Profile Management.
- [ ] **Shopping Lists**:
    - [ ] Create multiple lists (e.g., "Weekly Groceries", "Party").
    - [ ] Add products directly from Search/Home.
    - [ ] "Optimize List" feature: Which supermarket is cheapest for the *entire* list?
- [ ] **Price Alerts**:
    - [ ] Users subscribe to products.
    - [ ] Receive notification if price drops below a target.

## Phase 3: Advanced Features
Bring "Wow" factors to the application.

- [ ] **Barcode Scanning**:
    - [ ] Use mobile camera to scan a product in-store.
    - [ ] Instantly show prices at other supermarkets.
- [ ] **Crowdsourcing**:
    - [ ] "Report a Price": Users can submit real-time prices they see in stores.
    - [ ] Gamification: Points/Badges for helpful users.
- [ ] **Geolocation**:
    - [ ] Map view of Supermarkets.
    - [ ] "Find cheapest X near me" logic.
- [ ] **History & Trends**:
    - [ ] Price history charts (e.g., "Milk price over last 3 months").

## Phase 4: Performance & Polish
- [ ] **PWA Support**: Installable on mobile phones.
- [ ] **Offline Mode**: View cached lists/prices without internet.
- [ ] **Search Optimization**: Fuzzy search, filters (Brand, Category, Price Range).
