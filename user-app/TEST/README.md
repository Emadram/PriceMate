# TEST Directory

This directory contains scripts for testing, seeding, and debugging the PriceMate application.

## Scripts

### Database Management

### Database Management

#### `clearDatabase.js`
**⚠️ DANGER**: Deletes ALL data from the database.

**Usage:**
```bash
export APPWRITE_API_KEY="your_api_key_here"
node TEST/clearDatabase.js
```

**What it does:**
- Deletes all prices
- Deletes all products
- Deletes all supermarkets
- Deletes all categories
- Includes 3-second safety delay

---

#### `seedDatabase.js`
Populates the Appwrite database with sample data for development and testing.

**Usage:**
```bash
export APPWRITE_API_KEY="your_api_key_here"
node TEST/seedDatabase.js
```

**What it does:**
- Creates 10 supermarkets (Carrefour, BIM, Migros, etc.)
- Creates 20 products across multiple categories
- Generates randomized prices for each product

---

#### `fixDatabase.js`
Repairs common database issues and cleans up orphan data.

**Usage:**
```bash
node TEST/fixDatabase.js
```

**What it fixes:**
- Creates fulltext search index (if possible)
- Removes orphan price entries (prices with no product)

---

### Testing & Verification

#### `fullSiteTest.js`
Comprehensive integration test that simulates user navigation through all pages.

**Usage:**
```bash
node TEST/fullSiteTest.js
```

**Tests:**
- ✅ Home Page: Featured products with categories
- ✅ Search: Product search functionality
- ✅ Price Comparison: Product details and pricing
- ✅ Supermarket Profile: Store listings

**Output:** `test_report.txt` with detailed results

---

#### `verifyFix.js`
Quick verification script to confirm relationship data is fetched correctly.

**Usage:**
```bash
node TEST/verifyFix.js
```

**Validates:**
- Product names are retrieved
- Supermarket names are retrieved
- Category names are retrieved

---

#### `checkRelationships.js`
Diagnostic tool to inspect Appwrite relationship data structure.

**Usage:**
```bash
node TEST/checkRelationships.js
```

**Checks:**
- How relationships are returned (arrays vs objects)
- Whether Query.select is needed
- Validates data integrity

---

## Setup Requirements

All scripts require the `APPWRITE_API_KEY` environment variable:

```bash
export APPWRITE_API_KEY="your_api_key_here"
```

## Recommended Workflow

1. **Initial Setup:**
   ```bash
   node TEST/seedDatabase.js    # Populate database
   node TEST/fullSiteTest.js    # Verify everything works
   ```

2. **After Schema Changes:**
   ```bash
   node TEST/fixDatabase.js     # Fix indexes/cleanup
   node TEST/fullSiteTest.js    # Re-test
   ```

3. **Debugging Issues:**
   ```bash
   node TEST/checkRelationships.js  # Inspect data structure
   node TEST/verifyFix.js           # Quick validation
   ```

## Test Reports

- `test_report.txt` - Generated by `fullSiteTest.js` with timestamped results
